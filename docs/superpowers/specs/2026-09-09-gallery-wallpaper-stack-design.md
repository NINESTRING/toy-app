# 갤러리 월페이퍼 스택 설계

> 상태: 구현과 함께 작성 · 2026-09-09
> 변경 범위: 앱 셸만. 기믹 핫패스(`src/gimmicks/*/index.tsx`)는 건드리지 않는다.

## 0. 무엇을 바꾸는가

홈 갤러리를 **2열 타일 그리드**에서 **잠금화면 월페이퍼처럼 보이는 색 띠
스택**으로 바꾼다. 레퍼런스는 사용자가 준 사진 한 장이다: 짙은 초록 배경 위에
가늘고 큰 숫자, 그 아래로 살짝 기울어진 둥근 띠가 짙은 초록 → 초록 → 크림으로
층층이 겹쳐 내려온다.

사진에서 가져오는 것 네 가지.

1. **단색 램프.** 여러 색이 아니라 한 계열(숲 초록)이 어두운 데서 밝은 데로
   내려가다 마지막에 크림으로 끊긴다. 이 대비가 사진의 정체다.
2. **띠 스택.** 띠 하나가 기믹 하나. 화면 폭을 다 쓰고, 다음 띠가 앞 띠의
   아래를 덮는다. 띠 사이에 배경색 가는 틈이 보인다.
3. **기울기.** 띠 전체가 오른쪽이 올라가게 몇 도 기울어져 있다. 글자도 함께
   기울어진다.
4. **헤더.** 작은 라벨 → 아주 큰 가는 숫자 → 가는 선과 짧은 캡션. 사진의
   시계 자리에 **모든 기믹을 만진 총 횟수**가 온다.

## 1. 레이아웃

```
토이앱                                 ☾
1,234                     ← 총 횟수, text-8xl font-extralight
────────
모두 만진 횟수
          ────────

╲‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾╲   키캡 · 156회      ⌨
 ╲‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾╲  다이얼 · 51회     ◎
  ╲‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾╲ 전구 · 돌리기      ☀
   …
```

- 띠: 폭 = 화면 폭, 높이 168, 다음 띠가 104 아래에서 시작(64 겹침).
  `rounded-3xl`, 배경색 3px 테두리가 띠 사이 틈이 된다.
- 기울기 -10°. 회전은 `Pressable`의 `style.transform`에 둔다 — 그래야 터치
  영역도 함께 돈다. 회전으로 위아래로 튀어나오는 만큼(`W/2 · sin10°`, 약 34)
  스택 위아래에 패딩을 준다. 좌우로 튀어나온 모서리는 ScrollView가 자른다 —
  사진에서 띠 끝이 화면 밖으로 잘리는 것과 같다.
- 띠의 보이는 부분은 위쪽 104·cos10° ≈ 102이므로 내용(이름·횟수·아이콘)은
  위쪽에 붙인다. 마지막 띠만 전체가 보인다.
- 카운트 0이면 입력모델 라벨(`KIND_LABELS`)을 대신 보여주는 규칙은 그대로.

## 2. 색 — 팔레트를 `@theme`에 올린다

`global.css`의 `@theme`에 여섯 색을 추가한다. 타일 그리드 설계가 "틴트를
테마 토큰으로 올리지 않는다"고 한 것과 다른 결정인데, 성격이 다르다. 그때
틴트는 기믹마다 다른 색이라 Tailwind 기본 팔레트(`blue-500`)로 충분했다.
이번 램프는 Tailwind에 없는 여섯 색이고 라이트/다크에서 순서만 뒤집혀 쓰이므로
`dark:` 변형으로 갈아끼울 이름이 필요하다. 시맨틱 토큰(`--color-primary`류)은
그대로 무채색이다.

| 이름 | 값 | 역할 |
|---|---|---|
| `forest-950` | `#0b3b2a` | 다크 배경 / 라이트 마지막 띠 |
| `forest-800` | `#0f5a3c` | 띠 |
| `forest-700` | `#137a4e` | 띠 |
| `forest-600` | `#1f9a62` | 띠 |
| `sage-200` | `#cfe5d2` | 밝은 띠 |
| `cream-100` | `#f3e9d8` | 다크 마지막 띠 / 라이트 배경 |

다크: 배경 forest-950, 띠는 위에서부터 800 → 700 → 600 → sage → cream.
라이트: 배경 cream, 띠는 sage → 600 → 700 → 800 → 950. 어느 쪽이든 배경과
가장 가까운 밝기의 띠가 위에 오고 반대쪽 극이 아래에 온다.

글자색은 띠마다 정해진다 — 초록 띠 위엔 크림, sage·cream 위엔 forest-950.
위치별 `{surface, ink}` 5쌍을 리터럴 문자열로 적어둔다(Tailwind 스캐너 제약,
타일 그리드 설계 §3과 같은 이유). 기믹이 5개를 넘으면 `index % 5`로 돈다.

### 기믹별 틴트를 없앤다

띠가 단색 램프이므로 `look.tint`의 소비자가 사라진다. 죽은 데이터를 registry에
남기지 않는다 — `GimmickLook`에서 `tint`를 빼고 `lib/tints.ts`를 지운다.
"갤러리 색은 기믹 씬의 지배색"이라는 연속성은 잃는다. 사진이 요구한 것이
그것과 양립하지 않아 사진을 택했다. 되살리려면 `git log`의 타일 그리드 커밋에
전부 있다.

## 3. 유지하는 것

- 네이티브 헤더 끄기, `insets.top` 직접 처리.
- 마운트 시 전 기믹 `hydrate`(콜드 스타트 카운트 0 버그).
- 눌림 스프링 0.96 → 0.98(띠가 넓어 0.96은 과하다) + `nudge` 햅틱(실기기 미검증).
- `Link asChild → Pressable → Animated.View` 구조. 회전은 Pressable, 스케일은
  Animated.View.
